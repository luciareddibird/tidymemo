# なんでも帳 · Everything Book

思いついたことを、ひとまずここへ。
*Whatever comes to mind, set it down here.*

ブラウザだけで動く、日英バイリンガルのメモ帳です。

## 5つのステップ(ツェッテルカステン)

社会学者ニクラス・ルーマンが使ったメモ術「ツェッテルカステン」(ドイツ語で「メモの箱」)の流れを、画面の上に5つ並べています。

1. **書く** — ひとつのメモに、ひとつのアイデア。いちばん上の欄に書いて Enter。完璧でなくてかまいません。
2. **番号** — メモには自動で番号がつきます(1, 2, 3…)。あるメモの続きや枝分かれは「続きを書く」で、`1/1`、`1/2`、さらに `1/1/1` のように差し込めます。
3. **つなぐ** — 関係するメモ同士を、番号でつなぎます。つなぐときに「どうつながるか」をひとこと添えられます。つないだ先からも、元のメモが見えます(双方向)。
   - 「つながりそう」なメモの提案と、「過去のメモを見返す」ための数枚が出てきます。
   - 2枚をつないで新しい気づきが生まれたら「気づきを書く」で、両方につながった新しいメモが作れます。
   - どこともつながっていないメモは「ひとりぼっち」に集まります。
4. **見直す** — 1日後、3日後、1週間後…と間をあけて、読み返すメモが1日5枚まで出てきます。
5. **テーマ** — テーマごとに、関係するメモの番号を並べた一覧を作れます。並べ替えもできます。

コツ:完璧を目指さない/1日5分のスキマ時間で/「書く日」と「つなぐ日」をわけてもいい。

## できること

- **カテゴリーで色分け** — パステルの8色から選べます。カテゴリーの追加・名前の変更・削除もできます。
- **タイトル一覧** — タイトルをクリックすると、その場で中身がひらきます。
- **キーワード検索** — タイトルと本文から探します。スペースで区切ると、すべての言葉を含むメモに絞り込みます。
- **[[タイトル]] 書き** — 本文に `[[メモのタイトル]]` と書いても、そのメモとつながります。
- **グラフビュー** — メモ同士のつながりを、点と線の図で見られます。点には番号がつきます。色はカテゴリーの色です。点をクリックするとメモがひらき、ドラッグで動かせます。ホイールまたは ＋/− で拡大・縮小します。
- **ゴミ箱** — 半年以上ひらいていないメモは、自動でゴミ箱へ移ります。一枚ずつ「残す」か「消す」を選べます。
- **日本語 / English** — 右上で切り替えます(英語はイギリス式)。
- **保存** — 「保存」ボタン、または Ctrl+S / ⌘+S。
- **バックアップ** — JSON ファイルに書き出し、読み込みができます。

## 使い方

`index.html` をブラウザで開くだけです。サーバーもインストールもいりません。

メモは、開いたブラウザの中(localStorage)に保存されます。別の端末やブラウザとは共有されません。ブラウザのデータを消すとメモも消えるので、ときどき「バックアップを保存」で書き出してください。
