# なんでも帳 · Everything Book

思いついたことを、ひとまずここへ。
*Whatever comes to mind, set it down here.*

ブラウザだけで動く、日英バイリンガルのメモ帳です。

## 4つのステップ(ツェッテルカステン)

画面の上に、メモを育てる流れが4つ並んでいます。数字が出ているところが「次にやること」です。

1. **集める** — 上の入力欄に、思いついたことやURLを入れて Enter。「たね」として保存されます。
2. **育てる** — たねをひらいて、自分の言葉で書き直します。「育て終わった」を押すとメモになります。
3. **つなぐ** — メモの中の「メモとつなぐ」で、関係するメモとつなげます(つながりそうなメモも提案します)。Googleドキュメントなどの資料のリンクも付けられます。どこともつながっていないメモは「ひとりぼっち」に集まります。
4. **見直す** — 1日後、3日後、1週間後…と、間をあけて読み返すメモが、1日5枚まで出てきます。「見直した」を押すと、次はもう少し先に出てきます。

## できること

- **カテゴリーで色分け** — パステルの8色から選べます。カテゴリーの追加・名前の変更・削除もできます。
- **タイトル一覧** — タイトルをクリックすると、その場で中身がひらきます。
- **キーワード検索** — タイトルと本文から探します。スペースで区切ると、すべての言葉を含むメモに絞り込みます。
- **[[リンク]]** — 本文に `[[メモのタイトル]]` と書くと、そのメモへのリンクになります。まだないタイトルなら、クリックで新しいメモができます。
- **グラフビュー** — メモ同士のつながりを、点と線の図で見られます。色はカテゴリーの色です。点をクリックするとメモがひらき、ドラッグで動かせます。ホイールまたは ＋/− で拡大・縮小します。
- **ゴミ箱** — 半年以上ひらいていないメモは、自動でゴミ箱へ移ります。一枚ずつ「残す」か「消す」を選べます。
- **日本語 / English** — 右上で切り替えます(英語はイギリス式)。
- **保存** — 「保存」ボタン、または Ctrl+S / ⌘+S。
- **バックアップ** — JSON ファイルに書き出し、読み込みができます。

## 使い方

`index.html` をブラウザで開くだけです。サーバーもインストールもいりません。

メモは、開いたブラウザの中(localStorage)に保存されます。別の端末やブラウザとは共有されません。ブラウザのデータを消すとメモも消えるので、ときどき「バックアップを保存」で書き出してください。
